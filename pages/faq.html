Frequently Asked Questions

Find answers to common questions about Nethxeum.

What is Nethxeum?
Nethxeum (NTU) is a privacy-focused cryptocurrency that combines Bitcoin-like scarcity (42M hard cap, halving schedule) with Monero-grade privacy (ring signatures, RingCT, stealth addresses). It uses the RandomX proof-of-work algorithm for democratic, CPU-friendly mining.
How is Nethxeum different from Bitcoin?
While Bitcoin offers transparent transactions and a 21M supply cap, Nethxeum provides mandatory privacy for all transactions and a 42M supply cap. Nethxeum also uses RandomX for ASIC-resistant CPU mining, whereas Bitcoin mining is dominated by specialized ASIC hardware.
How is Nethxeum different from Monero?
Monero has unlimited supply with a tail emission of 0.6 XMR per minute forever. Nethxeum has a hard cap of 42 million NTU with no tail emission, following a Bitcoin-style halving schedule. This creates predictable scarcity while maintaining the same privacy features.

How do I mine Nethxeum?
You can mine Nethxeum using any modern CPU with the RandomX algorithm. Download the daemon and use the --start-mining flag, or use a mining pool with XMRig. For optimal performance, enable huge pages and use physical CPU cores rather than hyper-threads. See our Mining Guide for detailed instructions.
What are the system requirements?
Minimum: 2 CPU cores, 4GB RAM, 50GB SSD, Ubuntu 20.04 / Windows 10.
Recommended: 4+ CPU cores, 8GB+ RAM, 200GB NVMe, Ubuntu 22.04 LTS.
For the GUI wallet, you need a modern GPU with OpenGL 3.0+ support.
Is Nethxeum anonymous?
Nethxeum provides strong privacy guarantees through cryptographic techniques: ring signatures hide the sender, RingCT hides transaction amounts, and stealth addresses hide the recipient. Where can I buy NTU?
Nethxeum is currently in its early stages. The best way to acquire NTU is through mining. Exchange listings are planned for Phase 3 of the roadmap (2026). Always be cautious of unofficial exchanges and potential scams.
How do I store NTU safely?
Download the official Nethxeum GUI Wallet or use the CLI wallet. Always back up your 25-word seed mnemonic securely (write it down, never store digitally). Use a strong password and consider running your own full node for maximum privacy. Never share your seed or private keys with anyone.
