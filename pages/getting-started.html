Getting Started

Your journey into private finance begins here.

Step 1
Learn About Nethxeum
Read What is Nethxeum? to understand the project's goals, technology, and unique value proposition.
Step 2
Download the Software
Get the GUI Wallet (recommended for beginners) or the daemon for your operating system. Verify the checksum.
Step 3
Install and Sync
Install the wallet and wait for the blockchain to synchronize. This may take several hours. You can use a remote node for instant access.
Step 4
Create Your Wallet
Generate a new wallet and securely write down your 25-word seed mnemonic. This is the only way to recover your funds. Never lose it.
Step 5
Start Using Nethxeum
Receive NTU by sharing your address, or start mining to earn block rewards. You can also run a full node to support the network.

Quick Tips

  • Backup your seed immediately. Write it on paper and store it somewhere safe and fireproof.
  • Use a strong password. Your wallet file is encrypted, but a weak password can be brute-forced.
  • Run your own node. For maximum privacy, sync the full blockchain rather than using remote nodes.
  • Join the community. Our Discord and Telegram are great places to get help and stay updated.
