Contribute to Nethxeum

Development

Contribute code to the Nethxeum daemon, GUI wallet, or ecosystem tools. We welcome developers of all skill levels.

  • C++ developers for daemon improvements
  • Qt/QML developers for GUI wallet
  • Web developers for ecosystem tools
GitHub Repositories

Testing & QA

Help test new releases, report bugs, and verify fixes. Quality assurance is critical for financial software.

  • Test wallet functionality
  • Verify daemon synchronization
  • Test on different platforms
Report Issues

Write guides, improve documentation, and translate content to make Nethxeum accessible worldwide.

  • User guides and tutorials
  • Developer documentation

Donations

Nethxeum development is funded entirely by community donations. There is no premine, no developer tax, and no corporate backing. If you believe in private finance, consider donating to support ongoing development.
