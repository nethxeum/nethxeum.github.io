# Nethxeum website

## Run locally on Replit

This is a static multi-page website. The configured `Start application` workflow serves the project on port 5000 with:

```bash
python3 -m http.server 5000 --bind 0.0.0.0
```

Open `index.html` for the homepage. Shared styling lives in `css/main.css`, and shared interactions/translations live in `js/main.js`.
